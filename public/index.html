Settings

Environment variables FORGE_BASE_URL / FORGE_API_KEY / FORGE_MODEL override these.

Enable or disable the tools Halo AI Harness may use. Disabled tools are hidden from the model and calls to them are rejected. External tools can be added as MCP servers in ~/.forge/mcp.json or <workspace>/.forge/mcp.json.

The base prompt is resolved from the first file that exists: <workspace>/.forge/system.md → global ~/.forge/system.md → the built-in prompt/system.md in the Halo AI Harness repo. A chat.md file at the same locations does this for Chat mode. AGENTS.md in the workspace is always appended as project instructions; ~/.forge/append.md extends every prompt.
